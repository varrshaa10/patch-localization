# Summary of Changes Made to Main Project

## Overview
This document lists all changes made to fix issues discovered during fresh review testing.

## Files Modified

### 1. README.md
**Changes made:** 3 sections corrected

#### Change 1: Dataset Generation Command
**Location:** "Generate Synthetic Dataset" section  
**Before:**
```bash
python dataset/generate_dataset.py --architecture both --num_pairs 40 --output_dir ../tests/synthetic_data
```

**After:**
```bash
python dataset/generate_dataset.py --architecture both --num_pairs 40 --output_dir ./tests/synthetic_data
```

**Reason:** Using `../tests/synthetic_data` creates files at ROOT level, but batch_eval.py expects them in `algorithm/tests/synthetic_data/`. The corrected path creates files in the correct location.

---

#### Change 2: Inference Example Filename
**Location:** "Run Inference on a Single Pair" → Example command  
**Before:**
```bash
python infer.py --reference ../../tests/synthetic_data/pair_0_ref.png --search ../../tests/synthetic_data/pair_0_search.png
```

**After:**
```bash
python infer.py --reference ../tests/synthetic_data/pair_0_reference.png --search ../tests/synthetic_data/pair_0_search.png
```

**Reason:** Generated files are named `pair_0_reference.png` not `pair_0_ref.png`. Also corrected the relative path (from `algorithm/core` to files in `algorithm/tests/synthetic_data/` is `../`, not `../../`).

### 2. algorithm/core/batch_eval.py
**Changes made:** 1 function (path handling)

**Before:**
```python
import csv
import time
import numpy as np
from infer import run_inference

results = []
with open("../tests/synthetic_data/ground_truth.csv") as f:
    rows = list(csv.DictReader(f))

for row in rows:
    pair_id = row["pair_id"]
    ref_path = row["ref_path"]
    search_path = row["search_path"]
    gt_x, gt_y = float(row["gt_x"]), float(row["gt_y"])
    add_marker = row.get("add_marker", "")
```

**After:**
```python
import csv
import time
import numpy as np
import os
from infer import run_inference

results = []
with open("../tests/synthetic_data/ground_truth.csv") as f:
    rows = list(csv.DictReader(f))

for row in rows:
    pair_id = row["pair_id"]
    # Adjust paths: CSV contains paths relative to algorithm/, but we run from algorithm/core
    ref_path = os.path.join("..", row["ref_path"])
    search_path = os.path.join("..", row["search_path"])
    gt_x, gt_y = float(row["gt_x"]), float(row["gt_y"])
    add_marker = row.get("add_marker", "")
```

**Reason:** The CSV generated by `generate_dataset.py` stores paths relative to the `algorithm/` directory (e.g., `./tests/synthetic_data/pair_0_reference.png`). However, `batch_eval.py` runs from `algorithm/core/`, so it needs to adjust these paths by prepending `../` to make them correct relative to the actual working directory.
